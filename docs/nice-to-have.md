# Nice to have

Work intentionally deferred from specs and plans. Each entry: what, why deferred, trigger to
revisit, reference. Remove an entry when it ships or when the trigger is retired.

## Homebrew tap for the fleet

- **What:** `brew install sulcer/tap/gaugewire` for the Mac Minis, generated by goreleaser.
- **Why deferred:** needs a second repository and a token; plain binaries cover the first rollout.
- **Trigger:** the second machine is installed by hand.
- **Reference:** [repo scaffold spec](spec/repo-scaffold/README.md), CI and release.

## Verify ingestion before acknowledging

- **What:** keep a delivered event spooled as `submitted` until `GET .../ingestions/{id}` reports
  `success`; dead-letter on `failed`.
- **Why deferred:** ack-on-accept is simpler and an async failure of a fixed schema is a bug
  caught on the first run, not an operating condition.
- **Trigger:** `doctor` ever reports a `failed` ingestion on a healthy configuration.
- **Reference:** [ADR](adr/2026-09-17-databox-sink-targets-v1-and-acks-on-accept.md).

## Requeue automation

- **What:** automatic requeue of dead-letter events after credentials or dataset ids change.
- **Why deferred:** `gaugewire flush --requeue` is explicit and rare.
- **Trigger:** a second machine needs a requeue after a key rotation.
- **Reference:** [spool and flush](spec/gaugewire/spool-and-flush.md).

## Additional sinks

- **What:** OTLP, generic webhook, file sink.
- **Why deferred:** the v1 goal is one working destination behind a stable interface.
- **Trigger:** a second destination is actually wanted.
- **Reference:** [architecture](spec/gaugewire/architecture.md), extension points.

## Subagent status line and spend limit window

- **What:** observe `subagentStatusLine` input and the `rate_limits.spend_limit` window.
- **Why deferred:** neither carries the five-hour or seven-day subscription quota.
- **Trigger:** a gateway spend limit becomes part of the fleet.
- **Reference:** [data contract](spec/gaugewire/data-contract.md).

## SBOM, signing, CodeQL

- **What:** syft SBOM and cosign signatures on releases; CodeQL scanning.
- **Why deferred:** binaries stay inside the fleet; CodeQL needs GitHub Advanced Security on a
  private repo.
- **Trigger:** binaries are distributed outside the fleet or the repo goes public.
- **Reference:** [repo scaffold spec](spec/repo-scaffold/README.md).

## Docs-impact tool

- **What:** map a diff to the spec pages that should be re-read, from a `code:` pointer in each
  spec page's frontmatter. Retrieval only, never a staleness verdict, optimised for recall.
- **Why deferred:** the spec is small enough to re-read whole.
- **Trigger:** a spec drift is found in review twice.
- **Reference:** [documentation system ADR](adr/2026-09-17-documentation-system.md).
